# robur_mcp

`robur_mcp` — плагин для Topomatic Robur, предоставляющий внешним языковым моделям и агентам доступ к инструментам платформы через MCP-сервер.

Проект состоит из двух частей:

- `tool_bridge` - C#-плагин для Topomatic Robur, работающий внутри платформы и получающий доступ к активному проекту и моделям.
- `mcp_server` - Python HTTP MCP-сервер, принимающий и проксирующий MCP-запросы в плагин через Windows named pipe.

## Структура репозитория

```text
robur_mcp/
|- tool_bridge/         C#-плагин для Topomatic/Robur
|- mcp_server/          Python MCP-сервер
|- scripts/             служебные скрипты
|- tests/               тесты проекта
|- Out/                 выходные артефакты и зависимости среды Topomatic Robur
\- README.md
```

## Правила оформления C#-кода

При создании и редактировании C#-файлов (`.cs`) соблюдай следующие правила:

- Сохраняй файлы в кодировке UTF-8 с BOM.
- Используй окончания строк CRLF (`\r\n`).
- Используй 4 пробела (SPC) на каждый уровень отступа. Не используй символы табуляции для отступов.
- Именуй поля с префиксом `m_` и основной частью в PascalCase, например `m_Field`, `m_PipeServer`.
- Именуй константы (`const`) в UPPER_SNAKE_CASE: заглавные буквы с разделением слов символом подчёркивания, например `CONSTANT_NAME`, `DEFAULT_PORT`. Для констант не используй префикс `m_`.
- При объявлении локальных переменных предпочитай `var`, если компилятор может вывести нужный тип из инициализатора. Указывай тип явно, если вывод типа невозможен или требуется тип, отличный от выводимого (например, интерфейс вместо конкретного класса).
